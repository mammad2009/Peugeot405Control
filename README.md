# Peugeot405Control

برنامه‌ی کنترل ماکت پنوماتیک پژو ۴۰۵ از طریق بلوتوث (HC-05).

## مراحل برنامه
1. **انیمیشن شروع** – مثل نمایشگر OLED ماکت: اول `MINI GARAGE MAMMAD` ، بعد لوگوی پژو و `PEUGEOT 405` (با لمس صفحه رد می‌شود).
2. **صفحه‌ی اتصال** – فقط یک دکمه‌ی اتصال به ماژول بلوتوث. بعد از اتصال موفق محو می‌شود.
3. **ریموت پژو** – با انیمیشن وسط صفحه ظاهر می‌شود. بعد از زدن «باز» کوچک می‌شود و می‌رود داخل منوی برنامه.
4. **منوی اصلی** – فقط کنترل: جلو / عقب / هر دو ، میباخ ، فابریک. ریموت را از دکمه‌ی قفل بالای صفحه دوباره باز کن.

## فرمان‌هایی که به ماژول فرستاده می‌شود
| دکمه | فرمان |
|---|---|
| ریموت: قفل | `K` |
| ریموت: باز | `U` |
| هر دو بالا (تا وقتی نگه داری) | `W` ، رها کردن: `0` |
| هر دو پایین (تا وقتی نگه داری) | `D` ، رها کردن: `0` |
| ارتفاع فابریک | `1` سپس `X` (اگر میباخ روشن باشد `N`) |
| جلو / عقب / میباخ | مثل قبل (`F B 2 1 R L Z X M N 0`) |

همه‌ی فرمان‌ها از تب «فرمان‌ها» داخل برنامه قابل ویرایش هستند.
